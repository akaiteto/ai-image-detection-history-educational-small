# AI画像の検出技術を、時代ごとに小さく試すサンプル（学習用）

X記事「AI画像を見抜く技術の歴史」とセットのソース。CPUと numpy だけで動く（通信なしで動かせる）。

## 動かし方
```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python compare.py
```

## 中身と論文の対応
| ファイル | 記事の図 | 論文 | このソースでの簡略化 |
|---|---|---|---|
| data.py | 図3〜6 | － | 本物の写真や生成AIは使わない。作り方の違いだけをまねた32x32の白黒画像を作る |
| methods/era1_classifier.py | 図3-A | CNNDetection（arXiv 1912.11035） | ResNet-50 の代わりに、細かい模様の特徴8個＋ロジスティック回帰 |
| methods/era1_frequency.py | 図3-B | Dzanic ら（arXiv 1911.06465） | いちばん細かい周期の強さだけを見る（学習なし） |
| methods/era3_reconstruction.py | 図5-A | DIRE（arXiv 2303.09295） | 拡散モデルの代わりに「ならす処理」で作り直す。分類器は使わず誤差の大きさだけ |
| methods/era3_feature_nn.py | 図5-B | UnivFD（arXiv 2302.10174） | CLIP の代わりに、乱数で作って固定した3x3の窓48個の反応を特徴にする |
| methods/era4_ae_reconstruction.py | 図6-A | AEROBLADE（arXiv 2401.17879） | オートエンコーダの代わりに「4x4平均で縮めて、なめらかに戻す」 |
| methods/era4_zeroshot.py | 図6-B | ZED（arXiv 2409.15875） | 本物だけで作る「次の画素の予想」を、左・上の画素からの直線のモデルにする |
| compare.py | － | － | 6つの方法を同じデータで並べ、AUC を表にする |

## 実装していないもの（理由）
- 拡散モデル本体（図4-A）：重く、学習済みの重みのダウンロードが要るため
- CLIP の重み（図5-B）：ダウンロードが要るため。固定の乱数の特徴で「本物/偽物の学習をしていない特徴」の役だけをまねた
- MLLM による説明つきの判定（図7-A）：大きなモデルが要るため
- 電子透かし（図8-B）

## 結果の読み方（注意）
- 数字は AUC（0.5＝当てずっぽう、1.0＝完全に見抜ける）。
- データがおもちゃなので、論文の数字や順位とは比べられない。見てほしいのは傾向だけ。
  - GANだけで学習した分類器は、作り方の違う相手（ldm）で大きく崩れる
  - 周波数のクセを見る方法は、規則的なクセのない相手（diffusion）で弱くなる
  - 作り直し型は、自分と同じ作り方の画像に強く効く
